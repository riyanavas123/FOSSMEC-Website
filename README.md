# FOSSMEC-Website
This website is designed to introduce FOSSMEC, showcase its vision and community, and highlight its workshops, competitions, and other activities. It serves as a platform for students to explore open-source technologies, learn new skills, and participate in collaborative projects.

## Technologies Used
HTML5 and CSS3.

## Setup Instructions
1. Clone the repository or download it as a ZIP file.
2. Extract the downloaded files.
3. Open the project folder in Visual Studio Code.
4. Open Structure.html in a web browser to view the website.

## Design Inspiration
The website is designed with a modern, clean, and visually engaging interface. It uses a consistent colour scheme, clear typography, and organized sections to make the content easy to explore. The layout focuses on simple navigation and an engaging presentation of the club's vision, activities, workshops, competitions, and community. Images are used to make the website more visually appealing and to highlight the events and experiences .
