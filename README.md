# FOSSMEC-Website
This website is designed to introduce FOSSMEC, showcase its vision and community, and highlight its workshops, competitions, and other activities. It serves as a platform for students to explore open-source technologies, learn new skills, and participate in collaborative projects.

Technologies Used HTML5 and CSS3.

Setup Instructions
Clone or download this repository.
Open the project folder in Visual Studio Code or any code editor.
Open Structure.html in a web browser to view the website.

Design Aspirations
Create a modern, clean, and visually appealing interface.
Maintain a consistent colour scheme and layout throughout the website.
Make navigation simple and user-friendly.
Highlight the community, workshops, competitions, and activities effectively.
Provide a responsive and accessible experience across different screen sizes.
Reflect the spirit of open-source collaboration, creativity, and innovation.
